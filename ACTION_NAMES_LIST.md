## 📝 COMO USAR

### Exemplo Básico
```json
{
    "ActionNames": ["Eat"],
    "ExecutionAmount": 3,
    "AllowedClassNames": []
}
```
Jogador precisa comer 3 vezes (qualquer comida).

### Exemplo com Item Específico
```json
{
    "ActionNames": ["ActionPlantSeed"],
    "ExecutionAmount": 5,
    "AllowedClassNames": ["PumpkinSeeds", "TomatoSeeds"]
}
```
Jogador precisa plantar 5 sementes (abóbora ou tomate).

### Exemplo Múltiplas Actions
```json
{
    "ActionNames": ["Eat", "Drink", "Bandage"],
    "ExecutionAmount": 1,
    "AllowedClassNames": []
}
```
Jogador precisa executar qualquer uma dessas ações 1 vez.

---

## ⚠️ OBSERVAÇÕES IMPORTANTES

1. **Case Sensitive**: ActionNames são sensíveis a maiúsculas/minúsculas
2. **AllowedClassNames**: Se vazio `[]`, aceita qualquer item
3. **ExcludedClassNames**: Lista de itens que NÃO contam
4. **ExecutionAmount**: Número total de vezes que a ação deve ser executada
5. **Múltiplas Actions**: Se listar várias, qualquer uma delas conta para o objetivo

---

## 🔍 COMO DESCOBRIR MAIS ACTIONS

### Método 1: Logs do Servidor
Ative logs de debug e execute ações no jogo. O nome da action aparecerá nos logs.

### Método 2: Arquivos do Mod
Procure em `@DayZExpansion/Scripts/` por arquivos `.c` que contenham `ActionBase`.

### Método 3: Teste e Erro
Crie um objetivo de teste e veja se funciona. Se não funcionar, o log do servidor mostrará erro.
