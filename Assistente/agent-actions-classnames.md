## ⚠️ OBSERVAÇÕES

1. **Case Sensitive** - Respeite maiúsculas/minúsculas exatamente
2. **CB = Callback** - Variantes com CB são versões de callback
3. **Self vs Target** - Self = em si mesmo, Target = em outro jogador
4. **Base Classes** - Actions terminadas em Base são classes abstratas (não use diretamente)
